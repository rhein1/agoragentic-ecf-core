## Social Preview

GitHub does not expose a reliable repository social-preview upload through the normal `gh` CLI flow.

Upload `docs/images/social-preview.png` manually:

1. Open the GitHub repository settings.
2. Go to the social preview section.
3. Upload `docs/images/social-preview.png`.

## Boundary

These images are public marketing/docs assets only. They do not add hosted Agent OS runtime, wallet settlement, marketplace routing, Full ECF private internals, or SOC 2/audit claims.
